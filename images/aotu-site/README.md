## GitHub Pages 올리는 법
1. GitHub에서 **Public** 저장소를 새로 만든다.
2. 이 폴더 안의 파일 전체(index.html, css, js, images …)를 저장소 맨 위(루트)에 올린다.
3. 저장소 **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 에서 확인한다.

> GitHub Pages는 대소문자를 구분합니다. 파일명과 코드의 경로 대소문자가 같아야 합니다.
